First independent Komelia Bigme release, based on upstream Komelia 0.20.0.

- Preserve Bigme hardware refresh, configurable delay and repeat count, and wait for gestures to finish before refreshing.
- Include upstream 0.20.0 features and migrate existing fork databases without overwriting E-Ink settings.
- Check this fork for app updates. Install this first APK manually over your previous Bigme build; later versions can update from inside Komelia.

Android arm64-v8a. The package name and signing identity match the previous Bigme build.
